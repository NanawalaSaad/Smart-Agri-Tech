🔧 Hardware Integration Guide

Connect real IoT sensors to Desert AgriTech AI system

Your physical sensors send live data → Our AI predicts yield + recommends crops → Results visible on mobile, laptop & LCD display

📦 Hardware Components Required

🧠

ESP32 Dev Board

Main microcontroller with built-in WiFi. Collects sensor data and sends to AI server.

🌡️

DHT22 Sensor

Measures Temperature (°C) and Humidity (%) simultaneously with high accuracy.

💧

Soil Moisture Sensor

Capacitive type recommended for desert use — measures soil water content %.

⚗️

pH Sensor Module

Analog pH sensor measures water/soil acidity. Critical for hydroponic optimization.

☀️

LDR / Light Sensor

Photoresistor module measures light intensity to track daily sunlight exposure.

📟

LCD Display (16x2)

Optional — shows live sensor readings and AI predictions without needing a screen.

📋 How to Connect — Step by Step

1

Assemble Hardware

Connect all sensors to ESP32 as per the diagram above. Use breadboard + jumper wires. Power via USB or 5V adapter.

2

Upload Arduino Code

Flash the ESP32 with our sensor code using Arduino IDE. Code reads all sensors every 30 seconds and sends data via WiFi HTTP POST to the AI server.

3

Connect to Same WiFi

ESP32 and your laptop/server must be on same WiFi network. Update the server IP address in ESP32 code to match your laptop's local IP.

4

Start Flask Server

Run python api/app1.py on your laptop. Server starts at port 5000. ESP32 will now auto-send data and receive AI predictions.

5

Access from Any Device

Open browser on mobile or laptop. Go to http://[your-laptop-IP]:5000 to see live predictions from real sensor data.

❓ FAQ — Common Questions

Where to use this system?
Best for hydroponic farms, greenhouse setups, research labs, and desert agricultural projects. Ideal for Saudi Arabia, UAE, and other arid regions where water efficiency and crop optimization are critical.
When should I take sensor readings?
For best results, take readings at early morning (6-7 AM) and late afternoon (5-6 PM). Desert temperatures fluctuate significantly — morning readings give baseline conditions, afternoon shows peak stress.
How accurate are the predictions?
Our XGBoost model achieves 92.58% accuracy (R² score). Predictions improve further when using real sensor data instead of manual input. The crop recommendation uses weighted similarity scoring across 50 desert-suitable crops.
Best use case for this system?
Perfect for: small-scale desert hydroponic farms, agricultural research in arid zones, food security projects (aligned with Saudi Vision 2030), and university research demonstrations.
Can I use without hardware (simulation only)?
Yes! All pages work with manual slider/number input. Hardware integration is optional — it just makes predictions automatic and real-time without manual data entry.
