📦 Core Hardware Components Required

🧠

ESP32 Development Board

Primary microcontroller with integrated WiFi. Collects sensor data and sends it to the AI server.

🌡️

DHT22 Sensor

Measures Temperature (°C) and Humidity (%) simultaneously with high accuracy.

💧

Soil Resistive Sensor

Measures soil conductivity to accurately evaluate ground moisture content.

⚗️

pH Sensor Module

Analog pH sensor measures water/soil acidity. Critical for hydroponic optimization.

☀️

LDR / Light Sensor

Photoresistor module measures light intensity to track daily sunlight exposure.

🌧️

Rain Drop Sensor

Crucial for the Desert Shield module. Detects sudden flash precipitation.

📡

Ultrasonic Sensor

Monitors hydroponic reservoir levels to calculate precise water depletion.

📺

OLED Display (I2C)

High-contrast localized visualization of live telemetry directly at the physical farm site.

📋 Initialization Protocol

1

Assemble Hardware Circuit

Integrate the sensor array with the ESP32 using the designated GPIO pins. Ensure stable 5V power supply via USB or adapter.

2

Deploy Firmware

Flash the ESP32 with the sensor code using Arduino IDE. The logic loops every 30 seconds to post JSON telemetry to the server.

3

Network Synchronization

Ensure the ESP32 and the primary Flask host machine reside on the identical local WiFi network.

4

Execute Server Instance

Run `python app.py` with host set to `0.0.0.0`. The API is now actively listening for incoming hardware telemetry.

5

Access from Any Device

Open browser on mobile or laptop. Go to your local IP port 5000 to view live predictions.

❓ FAQ — Common Questions

Where to use this system?
Best for hydroponic farms, greenhouse setups, research labs, and desert agricultural projects. Ideal for Saudi Arabia, UAE, and other arid regions where water efficiency and crop optimization are critical.
When should I take sensor readings?
For best results, the hardware automatically streams data. However, critical evaluations should be reviewed early morning (6-7 AM) and late afternoon (5-6 PM). Desert temperatures fluctuate significantly — morning readings give baseline conditions, afternoon shows peak stress.
How accurate are the predictions?
Our Rule-Based Expert System achieves highly accurate scaling matches (up to 99.0%). Predictions optimize dynamically when using real sensor data instead of manual input. The crop recommendation uses weighted similarity scoring across the database.
Best use case for this system?
Perfect for: small-scale desert hydroponic farms, agricultural research in arid zones, food security projects (aligned with Saudi Vision 2030), and university research demonstrations.
Can I use without hardware (simulation only)?
The system is designed with a strict hardware failsafe. If sensors are disconnected (reading 0), the AI will block predictions to prevent crop loss due to false data. Hardware integration is mandatory for active predictions.
