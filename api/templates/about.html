🌾 Desert AgriTech

AI-Powered Hydroponic Yield Prediction System

Problem Statement

Saudi Arabia imports over 80% of its food due to its harsh desert climate. Hydroponic farming offers a water-efficient alternative, but optimizing growing conditions (temperature, light, nutrients, water) is complex and requires data-driven decision-making.

Solution

This project uses real-time IoT sensors (ESP32) and a Rule-Based Expert System database of 250 desert crops to predict yield and growth cycles. It serves predictions through a Flask API to an interactive web dashboard.

Pipeline

Sensor Data (IoT)
Feature Parsing
Expert Match Engine
Flask API
Web Dashboard

Tech Stack

Python, Flask, HTML/CSS/JS, C++ (ESP32 Arduino), IoT Sensors

Future Scope

Phase 2 integrates real-time IoT sensors (ESP32 + DHT22, soil moisture, pH sensors) to feed live data into this model, replacing simulated inputs with real hydroponic farm readings.
